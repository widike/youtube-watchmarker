First device setup

In your Supabase dashboard, copy the project ID from the project URL and the publishable key from Settings → API Keys. Enable anonymous sign-ins under Authentication → Sign In / Providers, then copy and run the setup SQL in SQL Editor. Complete the CAPTCHA setup, then choose Start syncing to connect this device; you can then create connection codes for your other devices.
